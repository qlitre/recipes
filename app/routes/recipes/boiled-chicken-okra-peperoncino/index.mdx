## 材料
- スパゲッティ … 100g
- ゆで鶏 … 1/2枚分
- オクラ … 4本
- まいたけ … 1/2パック
- にんにく … 2かけ
- 鷹の爪 … 1本
- [温泉卵](/recipes/onsen-tamago) … 1個

### 調味料
- オリーブオイル … 大さじ1
- 塩 … 適量
- 黒こしょう … 適量

### ゆで鶏の材料
[サーモス「基本のゆで鶏」](https://www.thermos.jp/recipe/detail/me_kihonyudetori.html)のレシピで作ったもの。
- 鶏もも肉 … 2枚
- 長ねぎ（青い部分） … 1/2本分
- しょうが … 1かけ
- 水 … 1L

### 資材
- シャトルシェフ
- フライパン
- ザル
- 計量カップ

## 作り方

### 1. **ゆで鶏を作る**
- 長ねぎを叩いてぶつ切り、しょうがはうす切りにする
- 鍋に鶏肉・水・長ねぎ・しょうがを入れて中火にかける
- 沸騰したらアクを取り、フタをせず弱火で5分加熱する
- 保温して30分置く

### 2. **下準備**
- ゆで鶏を食べやすい大きさに切る
- オクラはぶつ切り、まいたけは手でほぐし、にんにくはみじん切りにする
![切ったゆで鶏、オクラ、みじん切りのにんにくをのせたまな板と、ほぐしたまいたけ](/recipes/boiled-chicken-okra-peperoncino/step1.png)
- フライパンに水800mLを入れて沸かす
- パスタを6分茹でる（表示より1〜2分短く）
- 茹で汁を100mL取り分けておく
![茹で汁を入れた計量カップ](/recipes/boiled-chicken-okra-peperoncino/step2.png)
- パスタはザルにあげて分けておき、残りの茹で汁は捨てる

### 3. **具材を炒める**
- 空いたフライパンにオリーブオイルとにんにくを入れ、弱火で香りを出す
![オイルの中のみじん切りのにんにく](/recipes/boiled-chicken-okra-peperoncino/step3.png)
- 鷹の爪を加える
![にんにくの横に鷹の爪を加えたフライパン](/recipes/boiled-chicken-okra-peperoncino/step4.png)
- ゆで鶏を加える
![フライパンに加えたゆで鶏](/recipes/boiled-chicken-okra-peperoncino/step5.png)
- まいたけを加えて炒める
![ゆで鶏の上にまいたけを加えたフライパン](/recipes/boiled-chicken-okra-peperoncino/step6.png)
- オクラを加えて炒める
![ゆで鶏とまいたけの上にオクラを加えたフライパン](/recipes/boiled-chicken-okra-peperoncino/step7.png)
- 乳化させながら茹で汁を加えていく

### 4. **仕上げ**
- ザルにあげておいたパスタを加えて和える
- 皿に盛り、温泉卵をのせ、黒こしょうをふって完成
![温泉卵をのせたゆで鶏とオクラとまいたけのペペロンチーノ](/recipes/boiled-chicken-okra-peperoncino/hero.png)
