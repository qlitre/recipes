## 材料
- スパゲッティ … 100g
- [豚バラコンフィ](/recipes/low-temp-pork-belly-confit) … 100g
- 長ネギ … 1本
- まいたけ … 1/3パック
- にんにく … 2かけ
- 鷹の爪 … 1本
- [温泉卵](/recipes/onsen-tamago) … 1個

### 調味料
- オリーブオイル … 大さじ1
- 塩 … 適量
- 黒こしょう … 適量

### 資材
- フライパン
- ザル
- 計量カップ

## 作り方

### 1. **下準備**
- 豚バラコンフィを食べやすい大きさに切る
- 長ネギは斜め切り、まいたけは手でほぐす
![まな板に並べた切った豚バラコンフィ、斜め切りの長ネギ、まいたけ、にんにく、鷹の爪](/recipes/pork-confit-peperoncino/step1.png)
- フライパンに水800mLを入れて沸かす
- パスタを6分茹でる（表示より1〜2分短く）
![フライパンで茹でているスパゲッティ](/recipes/pork-confit-peperoncino/step2.png)
- 茹で汁を100mL取り分けておく
![茹で汁を入れた計量カップ](/recipes/pork-confit-peperoncino/step3.png)
- パスタはザルにあげて分けておき、残りの茹で汁は捨てる

### 2. **コンフィを焼く**
- 空いたフライパンに、コンフィを作ったときの油をひいて豚バラコンフィを焼く
![フライパンで焼き始めた豚バラコンフィ](/recipes/pork-confit-peperoncino/step4.png)
- 両面を焼いたら取り出しておく
![裏返して焼いている豚バラコンフィ](/recipes/pork-confit-peperoncino/step5.png)

### 3. **具材を炒める**
- 同じフライパン（コンフィの脂が残ったまま）にオリーブオイルを足し、刻んだにんにくを入れ、弱火で香りを出す
![オイルの中で加熱しているみじん切りのにんにく](/recipes/pork-confit-peperoncino/step6.png)
- 鷹の爪を加える
![にんにくの横に鷹の爪を加えたフライパン](/recipes/pork-confit-peperoncino/step7.png)
- 茹で汁を1/3ほど加える
![計量カップからフライパンに茹で汁を注ぐ様子](/recipes/pork-confit-peperoncino/step8.png)
- 長ネギとまいたけを加えて炒める
![フライパンに入れた長ネギとまいたけ](/recipes/pork-confit-peperoncino/step9.png)
- 乳化させながら残った茹で汁を加えていく

### 4. **仕上げ**
- ザルにあげておいたパスタを加えて和える
![長ネギとまいたけの横に茹でたパスタを加えたフライパン](/recipes/pork-confit-peperoncino/step10.png)
- 皿に盛り、豚バラコンフィと温泉卵をのせ、黒こしょうをふって完成
![豚バラコンフィと温泉卵をのせ、黒こしょうをふったペペロンチーノ](/recipes/pork-confit-peperoncino/hero.png)

## 注意点
- コンフィは低温調理済みだが、表面をしっかり焼いてから使う
